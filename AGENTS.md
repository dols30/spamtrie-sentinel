# Project guidance

Adapted from the portfolio and DeepTrace projects in this workspace.

- Implement focused changes, verify affected flows, and preserve unrelated work.
- Use Bun and the existing project scripts.
- Keep the React, Vite, Tailwind, and shadcn foundation.
- Use frontend-design and design-taste-frontend for visual work.
- Keep copy short and concrete. Comment only non-obvious decisions.
- Connect controls to real state. Avoid fake metrics and unsupported claims.
- Preserve route paths, local detection, and saved analysis history.
- Support keyboard navigation, mobile, system appearance, and reduced motion.
- Run type checking, lint, a production build, and browser verification.
- Do not push to GitHub without asking.
