# SpamTrie Sentinel

A modern spam detection application built with React, TypeScript, and a trie-based algorithm. This project provides an efficient and scalable solution for detecting spam content using advanced data structures.

## Features

- Real-time spam detection using trie data structures
- Modern UI with shadcn/ui components
- Interactive trie visualization
- Responsive design
- Type-safe development with TypeScript
- Efficient state management with React Query
- Client-side routing with React Router

## Tech Stack

- React 18
- TypeScript
- Vite
- shadcn/ui
- Tailwind CSS
- React Query
- React Router

## Getting Started

### Prerequisites

- Node.js 18 or higher
- npm 9 or higher

### Installation

1. Clone the repository:
```bash
git clone https://github.com/bashyaldolraj/spamtrie-sentinel.git
cd spamtrie-sentinel
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```
